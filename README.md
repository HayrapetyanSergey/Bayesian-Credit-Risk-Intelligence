# 1. Նախագծի համառոտ նկարագրություն

**Bayesian Credit Risk Intelligence**-ը բայեսյան վիճակագրության, տվյալների վերլուծության, հավանականային կանխատեսման և արհեստական բանականության մեթոդները համատեղող հետազոտական նախագիծ է։

Նախագծի հիմնական նպատակը վարկային քարտերի հաճախորդների հաջորդ ամսվա վճարային դեֆոլտի հավանականության գնահատումն է՝ հաշվի առնելով հաճախորդների նախկին վճարային կարգապահությունը և վիճակագրական անորոշությունը։

Ի տարբերություն մոտեցումների, որոնք սահմանափակվում են դեֆոլտի հավանականության մեկ կետային գնահատականով, բայեսյան մեթոդաբանությունը հնարավորություն է տալիս ստանալ հավանականության ամբողջական posterior distribution, գնահատել credible interval-ներ և կանխատեսել ապագա դեֆոլտների քանակի հնարավոր բաշխումը։

Նախագիծն ընդգրկում է հետևյալ հիմնական ուղղությունները.

1. Տվյալների նախնական մշակում և որակի ստուգում։
2. Exploratory Data Analysis (EDA)։
3. Հաճախորդների խմբավորում՝ ըստ վճարումների ուշացման։
4. Beta-Binomial Bayesian Model-ի կառուցում։
5. Posterior distribution-ի գնահատում։
6. Analytical, Grid Approximation և MCMC մեթոդների կիրառում։
7. Posterior Predictive Analysis։
8. Prior Sensitivity Analysis։
9. Held-out Model Validation։
10. R Shiny ինտերակտիվ Dashboard։
11. Google Gemini-ի վրա հիմնված AI Agent։
12. Python վիճակագրական գործիքների և LLM Function Calling-ի ինտեգրում։

Նախագիծը կառուցված է այնպես, որ վիճակագրական հաշվարկները, վիզուալիզացիաները և AI համակարգը գործեն փոխկապակցված, բայց առանձին բաղադրիչների միջոցով։

**Կարևոր սահմանափակում.** Համակարգը մշակվել է կրթական և հետազոտական նպատակներով։ Այն նախատեսված չէ իրական վարկային հայտերի ավտոմատ հաստատման կամ մերժման համար։

# 2. Հետազոտական հիմնախնդիրը

## 2.1. Խնդրի արդիականությունը

Վարկային ռիսկի գնահատումը ֆինանսական հաստատությունների ռիսկերի կառավարման կարևորագույն խնդիրներից է։

Բանկերն ու այլ վարկատու կազմակերպությունները պետք է գնահատեն, թե որքանով է հավանական, որ վարկառուն չկատարի իր վճարային պարտավորությունները։

Այս հավանականությունը սովորաբար նշանակվում է **Probability of Default (PD)**։

PD-ի գնահատումը կարող է օգտագործվել՝

- Վարկային պորտֆելի ռիսկայնության ուսումնասիրության համար։
- Հաճախորդների ռիսկային խմբերի համեմատության համար։
- Հնարավոր վարկային կորուստների սցենարային վերլուծության համար։
- Ռիսկերի մոնիթորինգի և կառավարչական որոշումների տեղեկատվական աջակցության համար։
- Վիճակագրական անորոշության գնահատման համար։

Սակայն PD-ի միայն մեկ թվային արժեքը բավարար չէ։

Օրինակ՝ երկու հաճախորդային խմբեր կարող են ունենալ նմանատիպ գնահատված դեֆոլտի հավանականություններ, բայց այդ գնահատականների անորոշությունը կարող է տարբեր լինել։

Բայեսյան վիճակագրությունը հնարավորություն է տալիս ուսումնասիրել և՛ հավանականության գնահատականը, և՛ դրա վերաբերյալ առկա անորոշությունը։

## 2.2. Հիմնական հետազոտական հարց

**Ինչպե՞ս կարող ենք բայեսյան վիճակագրության միջոցով գնահատել վարկային դեֆոլտի հավանականությունները տարբեր վճարային կարգապահություն ունեցող խմբերում, չափել գնահատականների անորոշությունը և կանխատեսել ապագա դեֆոլտների քանակը։**

## 2.3. Հետազոտության նպատակները

Հետազոտության նպատակներն են՝

1. Ուսումնասիրել վարկային քարտերի հաճախորդների վճարային վարքագծի և դեֆոլտի միջև կապը։
2. Առանձնացնել վճարումների ուշացման հիման վրա ձևավորված ռիսկային խմբերը։
3. Գնահատել յուրաքանչյուր խմբի posterior default probability-ն։
4. Հաշվարկել 95% credible interval-ներ։
5. Համեմատել խմբերի դեֆոլտի հավանականությունները։
6. Ուսումնասիրել տարբեր Bayesian estimation մեթոդների արդյունքների համաձայնությունը։
7. Կատարել MCMC convergence diagnostics։
8. Կառուցել posterior predictive distribution-ներ։
9. Գնահատել prior-ի ընտրության ազդեցությունը։
10. Իրականացնել held-out validation։
11. Արդյունքները ներկայացնել ինտերակտիվ Dashboard-ում։
12. Ավելացնել իրական AI Agent, որը կկարողանա աշխատել հետազոտության հաշվարկային գործիքների հետ։

# 4. Տվյալների նախնական մշակում

Տվյալների նախնական մշակումը իրականացվել է Python-ով։

Հիմնական ֆայլը՝

`src/data_preprocessing.py`

Մշակման ընթացքում իրականացվել են՝

1. Սյունակների անվանումների ստանդարտացում։
2. Տվյալների տեսակների և արժեքների ստուգում։
3. Բացակայող արժեքների ուսումնասիրություն։
4. Կրկնվող գրառումների և նույնացուցիչների ստուգում։
5. Որոշ կատեգորիկ կոդերի միավորում։
6. Թիրախային փոփոխականի ստուգում։
7. Ռիսկային խմբերի ստեղծում։
8. Արդյունքների պահպանում առանձին processed dataset-ներում։

Կրթության որոշ ոչ ստանդարտ կատեգորիաներ միավորվել են ընդհանուր կատեգորիայի մեջ։ Ամուսնական կարգավիճակի որոշ կոդեր նույնպես համապատասխանեցվել են մշակման կանոններին։

Վերջնական մշակված տվյալների հավաքածուն պարունակում է 30,000 դիտարկում և չունի բացակայող արժեքներ։

# 7. Բայեսյան մոդելի մաթեմատիկական ձևակերպում

Հետազոտության հիմնական վիճակագրական մոդելը Beta-Binomial Bayesian Model-ն է։

Մոդելը կառուցվում է յուրաքանչյուր ռիսկային խմբի համար առանձին։

## 7.1. Likelihood

Ենթադրենք՝

- $n_g$ — $g$ խմբի հաճախորդների քանակը։
- $y_g$ — տվյալ խմբում արձանագրված դեֆոլտների քանակը։
- $p_g$ — խմբի անհայտ դեֆոլտի հավանականությունը։

Դեֆոլտների քանակի համար օգտագործվում է Binomial distribution.

```math
Y_g \mid p_g \sim \mathrm{Binomial}(n_g,p_g)
```

Likelihood ֆունկցիան ունի հետևյալ տեսքը.

```math
P(Y_g=y_g \mid p_g)
=
\binom{n_g}{y_g}
p_g^{y_g}
(1-p_g)^{n_g-y_g}
```

Այս ձևակերպումը ենթադրում է, որ յուրաքանչյուր խմբի ներսում հաճախորդները տվյալ մոդելի պայմաններում ունեն ընդհանուր դեֆոլտի հավանականություն։

Դիտարկումները համարվում են պայմանականորեն անկախ՝ տվյալ խմբի $p_g$ պարամետրը ֆիքսելու դեպքում։

## 7.2. Prior Distribution

Դեֆոլտի անհայտ հավանականության համար օգտագործվում է Beta distribution.

```math
p_g \sim \mathrm{Beta}(\alpha,\beta)
```

Հիմնական մոդելում ընտրված է՝

```math
p_g \sim \mathrm{Beta}(1,1)
```

Այս բաշխումը համարժեք է [0,1] միջակայքի uniform distribution-ին։

Այն թույլ է տալիս մոդելի սկզբնական տարբերակում հավասար prior density վերագրել դեֆոլտի հավանականության բոլոր հնարավոր արժեքներին։

Միաժամանակ պետք է հաշվի առնել, որ Uniform prior-ը նույնպես կոնկրետ վիճակագրական ենթադրություն է, ոչ թե prior տեղեկատվության բացարձակ բացակայություն։

## 7.3. Posterior Distribution

Bayes-ի թեորեմի համաձայն՝

```math
P(p_g \mid y_g)
\propto
P(y_g \mid p_g)P(p_g)
```

Beta prior-ի և Binomial likelihood-ի համատեղման դեպքում posterior distribution-ը նույնպես Beta distribution է։

```math
p_g \mid y_g,n_g
\sim
\mathrm{Beta}
(
\alpha+y_g,\,
\beta+n_g-y_g
)
```

Այս հատկությունը կոչվում է conjugacy։

## 7.4. Posterior Mean

Դեֆոլտի հավանականության posterior mean-ը հաշվարկվում է հետևյալ բանաձևով.

```math
E[p_g \mid y_g,n_g]
=
\frac{\alpha+y_g}
{\alpha+\beta+n_g}
```

Այստեղ posterior estimate-ը համատեղում է prior-ի պարամետրերը և դիտարկված տվյալները։

## 7.5. 95% Credible Interval

Posterior distribution-ից հաշվարկվում են 2.5% և 97.5% quantile-ները։

Ստացված միջակայքը պարունակում է posterior probability-ի 95%-ը՝ ընդունված prior-ի, likelihood-ի և տվյալների պայմաններում։

Այս մեկնաբանությունը տարբերվում է հաճախականային confidence interval-ի մեկնաբանությունից։

# 8. Posterior Estimation Methods

Հետազոտության ընթացքում posterior distribution-ի գնահատման համար կիրառվել են տարբեր մեթոդներ։

## 8.1. Analytical Bayesian Inference

Beta-Binomial conjugacy-ի շնորհիվ posterior distribution-ը հնարավոր է ստանալ ճշգրիտ անալիտիկ ձևով։

Այս մեթոդով հաշվարկվում են՝

- Posterior mean
- Posterior variance
- Credible interval
- Posterior probability

Անալիտիկ լուծումն օգտագործվում է որպես հիմնական համեմատական հիմք։

## 8.2. Grid Approximation

Grid Approximation-ի դեպքում դեֆոլտի հավանականության հնարավոր արժեքները ներկայացվում են դիսկրետ ցանցով։

Յուրաքանչյուր արժեքի համար հաշվարկվում է prior-ի և likelihood-ի արտադրյալը։

Այնուհետև ստացված կշիռները նորմալացվում են՝ կազմելով posterior distribution-ի թվային մոտարկում։

Մեթոդը օգտակար է բայեսյան թարմացման մեխանիզմը վիզուալ և հաշվարկային ձևով հասկանալու համար։

## 8.3. Metropolis-Hastings MCMC

Նախագծում իրականացվել է Random-Walk Metropolis-Hastings ալգորիթմ։

Այն օգտագործվում է posterior distribution-ից ընտրանքներ ստանալու համար։

Ալգորիթմը կիրառում է logit-transformed parameterization, որը թույլ է տալիս աշխատել անսահման իրական առանցքի վրա՝ պահպանելով հավանականության արժեքների [0,1] միջակայքը համապատասխան հակադարձ փոխակերպմամբ։

MCMC-ի արդյունքները համեմատվել են անալիտիկ posterior գնահատականների հետ։

Այսպիսով, հետազոտությունն ընդգրկում է ինչպես ճշգրիտ անալիտիկ, այնպես էլ թվային և սիմուլյացիոն գնահատման մոտեցումներ։

```math
ESS_{min} \approx 2630
```

Արդյունքը գերազանցում է նախագծում օգտագործված 400 շեմը։

## 10.4. Acceptance Rate

Metropolis-Hastings ալգորիթմի միջին acceptance rate-ը կազմում է մոտ 45.75%։

Այն նկարագրում է առաջարկված անցումների ընդունման հաճախականությունը։

Acceptance rate-ը գնահատվում է այլ diagnostics-ի հետ միասին և ինքնին convergence-ի բավարար ապացույց չէ։

## 10.5. Մեկնաբանություն

Հաշվարկված ցուցանիշների համակցությունը ցույց է տալիս, որ MCMC sampling-ը բավարար որակ ունի տվյալ posterior distribution-ների գնահատման համար։

Սակայն MCMC convergence-ը չի ապացուցում, որ ընտրված վիճակագրական մոդելը ճիշտ է ներկայացնում բոլոր իրական տնտեսական գործընթացները։

# 11. Posterior Predictive Analysis

Posterior Predictive Analysis-ը նախագծի կարևորագույն բաղադրիչներից է։

Դրա նպատակը ոչ միայն դեֆոլտի հավանականությունը գնահատելն է, այլև ապագա հաճախորդների խմբում դեֆոլտների հնարավոր քանակը կանխատեսելը։

## 11.1. Posterior Predictive Distribution

Եթե ապագա խմբի հաճախորդների քանակը $m$ է, ապա՝

```math
Y_{new,g} \mid y_g,n_g
\sim
\mathrm{BetaBinomial}
(
m,\alpha+y_g,\beta+n_g-y_g
)
```

Այս բաշխումը հաշվի է առնում՝

1. Ապագա դեֆոլտների պատահական տատանումները։
2. Դեֆոլտի անհայտ հավանականության posterior uncertainty-ն։

## 11.2. Հիմնական կանխատեսման սցենար

Դիտարկենք յուրաքանչյուր ռիսկային խմբից 1,000 նոր հաճախորդ։

| Risk Group | Expected Defaults | 95% Predictive Interval |
|---|---:|---|
| No reported delay | 138.37 | 117–161 |
| 1-month delay | 339.57 | 307–373 |
| 2+ months delay | 695.40 | 662–728 |

Այս արդյունքները ցույց են տալիս, թե որքան տարբեր կարող է լինել ապագա դեֆոլտների սպասվող քանակը՝ կախված հաճախորդների նախորդ վճարային կարգավիճակից։

## 11.3. Լրացուցիչ սցենար

Դիտարկենք 500 ապագա հաճախորդ, որոնք ունեն երկու և ավելի ամսվա վճարային ուշացում։

Հաշվարկված արդյունքները՝

- Posterior PD՝ 69.54%
- Expected Defaults՝ 347.70
- 95% Predictive Interval՝ 326–369

Այսպիսով, սպասվում է մոտավորապես 348 դեֆոլտ։

95% predictive interval-ը ներկայացնում է ապագա դեֆոլտների քանակի հավանականային անորոշությունը՝ ընդունված մոդելի պայմաններում։

## 11.4. Կանխատեսման հիմնական ենթադրությունը

Կանխատեսումները ենթադրում են, որ ապագա հաճախորդներն իրենց համապատասխան խմբերում համեմատելի են պատմական տվյալների հաճախորդների հետ։

Եթե ապագա հաճախորդների կառուցվածքը կամ տնտեսական միջավայրը էապես տարբերվի, կանխատեսումների որակը կարող է նվազել։

# 12. Prior Sensitivity Analysis

Բայեսյան մոդելի արդյունքները կարող են կախված լինել prior distribution-ի ընտրությունից։

Այդ պատճառով իրականացվել է sensitivity analysis։

Դիտարկվել են հետևյալ prior-ները՝

```math
\mathrm{Beta}(1,1)
```

```math
\mathrm{Beta}(2,8)
```

```math
\mathrm{Beta}(5,5)
```

Այս prior-ները ներկայացնում են տարբեր սկզբնական ենթադրություններ դեֆոլտի հավանականության վերաբերյալ։

## Արդյունքների մեկնաբանություն

Մեր տվյալների հավաքածուում յուրաքանչյուր խմբի դիտարկումների քանակը համեմատաբար մեծ է։

Այդ պատճառով փորձարկված prior-ների փոփոխությունները posterior mean-ների վրա սահմանափակ ազդեցություն են ունեցել։

Սա վկայում է, որ հետազոտության հիմնական եզրահանգումները համեմատաբար կայուն են ընտրված prior-ների շրջանակում։

Այնուամենայնիվ, prior robustness-ը պետք է մեկնաբանել միայն փորձարկված prior-ների համատեքստում։

# 13. Held-out Validation և Model Assessment

Վիճակագրական մոդելի որակը հնարավոր չէ գնահատել միայն posterior estimation-ի ճշտությամբ կամ MCMC convergence-ով։

Անհրաժեշտ է ուսումնասիրել նաև մոդելի կանխատեսումները այնպիսի դիտարկումների վրա, որոնք չեն օգտագործվել համապատասխան posterior-ի գնահատման ընթացքում։

## 13.1. Train-Test Split

Իրականացվել է 80/20 բաժանում՝ ռիսկային խմբերի կառուցվածքը պահպանելով։

Training subset-ն օգտագործվել է խմբային posterior distribution-ների գնահատման համար։

Test subset-ն օգտագործվել է կանխատեսված և իրական դեֆոլտների համեմատության համար։

## 13.2. Held-out Validation Results

| Risk Group | Test N | Observed Defaults | Expected Defaults | 95% Predictive Interval | Coverage |
|---|---:|---:|---:|---|---|
| No reported delay | 4,636 | 585 | 655.61 | 604–708 | No |
| 1-month delay | 738 | 245 | 252.00 | 224–280 | Yes |
| 2+ months delay | 626 | 439 | 434.40 | 409–459 | Yes |

## 13.3. Արդյունքների վերլուծություն

Երեք խմբերից երկուսի դեպքում իրական դեֆոլտների քանակը գտնվում է կանխատեսված 95% posterior predictive interval-ի ներսում։

Սակայն No reported delay խմբում իրական դեֆոլտների քանակը կազմում է 585, մինչդեռ կանխատեսված միջակայքը 604–708 է։

Այսպիսով, տվյալ խմբում դիտարկված դեֆոլտների քանակը դուրս է 95% predictive interval-ից։

Սա կարևոր արդյունք է, որը ցույց է տալիս, որ մոդելը կարող է ունենալ calibration-ի կամ համապատասխանության սահմանափակումներ որոշ խմբերի համար։

## 13.4. Brier Score

Brier Score-ը գնահատում է հավանականային կանխատեսումների և իրական երկարժեք արդյունքների միջև քառակուսային սխալը։

```math
BS =
\frac{1}{N}
\sum_{i=1}^{N}
(p_i-y_i)^2
```

Ավելի ցածր Brier Score-ը նշանակում է ավելի լավ հավանականային կանխատեսում՝ տվյալ գնահատման պայմաններում։

## 13.5. Log Loss

Log Loss-ը գնահատում է մոդելի հավանականային կանխատեսումների համապատասխանությունը իրական արդյունքներին։

```math
LL =
-\frac{1}{N}
\sum_{i=1}^{N}
[
y_i\log(p_i)
+
(1-y_i)\log(1-p_i)
]
```

Այս ցուցանիշը հատկապես խիստ է պատժում բարձր վստահությամբ արված սխալ կանխատեսումները։

## 13.6. Ընդհանուր գնահատում

Մոդելի առավելություններից են՝

- Պարզ և մեկնաբանելի Bayesian կառուցվածքը։
- Posterior uncertainty-ի գնահատումը։
- MCMC-ի լավ convergence ցուցանիշները։
- Prior sensitivity-ի սահմանափակ ազդեցությունը։
- Posterior predictive uncertainty-ի հաշվարկը։

Հիմնական սահմանափակումներից է մեկ ռիսկային խմբի held-out predictive interval-ի անհաջող coverage-ը։

Հետևաբար, հետազոտության արդյունքները տեղեկատվական և վերլուծական նշանակություն ունեն, սակայն դեռ բավարար չեն մոդելը իրական ֆինանսական որոշումների համակարգում կիրառելու համար։

## 15.2. Python Statistical Tools

AI Agent-ը հասանելիություն ունի հինգ հիմնական գործիքի։

### get_dataset_summary

Վերադարձնում է՝

- Հաճախորդների քանակը։
- Դեֆոլտների քանակը։
- Ընդհանուր դիտարկված դեֆոլտի մակարդակը։
- Միջին տարիքը։
- Միջին վարկային սահմանաչափը։
- Տվյալների որակի հիմնական ցուցանիշները։

### get_risk_group_posterior

Հաշվարկում է՝

- Posterior PD։
- Posterior parameters։
- 95% Credible Interval։
- Խմբային նկարագրական վիճակագրություն։

### predict_defaults

Օգտագործում է Beta-Binomial posterior predictive distribution-ը՝ ապագա դեֆոլտների քանակը գնահատելու համար։

Վերադարձնում է՝

- Expected Defaults։
- 95% Predictive Interval։
- Posterior PD։
- Ընտրված շեմը գերազանցելու հավանականությունը։

### compare_risk_groups

Համեմատում է ռիսկային խմբերի posterior mean-ները և դրանց տարբերությունները տոկոսային կետերով։

### get_model_diagnostics

Վերադարձնում է MCMC convergence-ի և sampling-ի պահպանված արդյունքները։

## 15.4. Փորձարկված օրինակ

Հետազոտության վերարտադրելիությունն ապահովելու համար վիճակագրական հաշվարկներն առանձնացված են Dashboard-ից և AI համակարգից։

Հիմնական Python ծրագրերը նախատեսված են՝

1. Տվյալների նախնական մշակման։
2. Exploratory Data Analysis-ի։
3. Bayesian posterior estimation-ի։
4. MCMC sampling-ի։
5. Posterior predictive analysis-ի։
6. Model assessment-ի համար։

Հաշվարկված արդյունքները պահպանվում են `results/` պանակում։

Dashboard-ը օգտագործում է մշակված dataset-ը և պահպանված հաշվետվությունները։

AI Agent-ի գործիքները նույնպես աշխատում են նախագծի իրական տվյալների կամ արդյունքների հիման վրա։

Այս կառուցվածքը թույլ է տալիս ստուգել վիճակագրական հաշվարկները՝ առանց լեզվային մոդելի օգտագործման։

Ամբողջական վերահաշվարկի համար անհրաժեշտ է օգտագործել տվյալների նույն տարբերակը, Python կախվածությունների համատեղելի տարբերակները և MCMC-ի նույն կարգավորումները։

Պատահականացված գնահատման մեթոդների արդյունքները կարող են փոքր չափով տարբերվել, եթե random seed-երը կամ ծրագրային միջավայրը տարբեր են։


## Ավտոմատ թեստավորում (Automated Testing)

Նախագծի հիմնական Bayesian հաշվարկների ճշտությունը ստուգվում է `pytest` գրադարանի միջոցով։

Թեստերը գտնվում են՝

`tests/test_bayesian_model.py`

Թեստավորման շրջանակում ստուգվում են՝

1. Dataset-ի դիտարկումների և դեֆոլտների քանակները։
2. Ընդհանուր դիտարկված դեֆոլտի մակարդակը։
3. Beta-Binomial posterior distribution-ի պարամետրերը։
4. Posterior mean-ի հաշվարկը։
5. 95% credible interval-ի ճշտությունը։
6. Ռիսկային խմբերի posterior հավանականությունների դասավորությունը։
7. Posterior predictive mean-ը։
8. Posterior predictive interval-ը։
9. Անթույլատրելի prior պարամետրերի մշակումը։
10. Անթույլատրելի կանխատեսման ծավալի մշակումը։
11. Ռիսկային խմբերի համեմատությունը։
12. Պահպանված MCMC diagnostics-ի հիմնական ցուցանիշները։

Թեստերը գործարկելու հրամանը՝

```bash
python -m pytest tests/ -v
```

Թեստավորման արդյունքները հաստատում են նախագծի հիմնական հաշվարկային ֆունկցիաների ստուգված սցենարների հաջող կատարումը։

Միաժամանակ այս թեստերը չեն փոխարինում արտաքին վավերացմանը, ինտեգրացիոն թեստավորմանը կամ իրական ֆինանսական համակարգում մոդելի գնահատմանը։

# 20. Նախագծի հիմնական արդյունքները

Հետազոտության հիմնական եզրահանգումները հետևյալն են.

1. Ուսումնասիրված 30,000 հաճախորդների շրջանում դիտարկված դեֆոլտի ընդհանուր մակարդակը կազմում է 22.12%։

2. Վճարումների ուշացումը տվյալ ընտրանքում ուժեղ կապ ունի հաջորդ ամսվա դեֆոլտի հավանականության հետ։

3. Երկու և ավելի ամիս ուշացում ունեցող խմբի posterior PD-ն կազմում է մոտ 69.54%։

4. Beta-Binomial մոդելը հնարավորություն է տալիս հաշվարկել ոչ միայն կետային գնահատականներ, այլև posterior uncertainty։

5. Grid Approximation և MCMC մեթոդները հնարավորություն են տալիս թվային ձևով ուսումնասիրել posterior distribution-ը։

6. MCMC diagnostics-ը ցույց է տալիս բավարար convergence։

7. Posterior predictive analysis-ը հնարավորություն է տալիս գնահատել ապագա դեֆոլտների սպասվող քանակը և կանխատեսման անորոշությունը։

8. Փորձարկված prior-ների ընտրությունը սահմանափակ ազդեցություն ունի հիմնական posterior գնահատականների վրա։

9. Held-out validation-ը բացահայտել է մոդելի սահմանափակում՝ No reported delay խմբի կանխատեսման դեպքում։

10. R Shiny Dashboard-ը հնարավորություն է տալիս ինտերակտիվորեն ուսումնասիրել հետազոտության արդյունքները։

11. Google Gemini AI Agent-ը կարողանում է օգտագործել իրական Python վիճակագրական գործիքները և ձևավորել դրանց հիման վրա բացատրություններ։

# 21. Տնտեսական և գործնական նշանակությունը

Նախագծի գործնական նշանակությունը պայմանավորված է բայեսյան մեթոդների՝ ֆինանսական ռիսկերի կառավարման համար տրամադրած հնարավորություններով։

## 21.1. Ռիսկային խմբերի բացահայտում

Վճարային կարգապահության հիման վրա հաճախորդների խմբավորումը հնարավորություն է տալիս տեսնել, թե որ հատվածներում է դիտարկված դեֆոլտի հավանականությունն ավելի բարձր։

## 21.2. Անորոշության գնահատում

Credible interval-ները և posterior distribution-ները հնարավորություն են տալիս գնահատել ոչ միայն ռիսկի մակարդակը, այլև այդ գնահատականի վիճակագրական անորոշությունը։

## 21.3. Սցենարային պլանավորում

Posterior predictive distribution-ը հնարավորություն է տալիս հաշվարկել տարբեր թվով հաճախորդների դեպքում դեֆոլտների հավանական քանակները։

Սա կարող է օգտակար լինել վարկային պորտֆելի սցենարային վերլուծությունների և ռիսկային սթրես-սցենարների նախնական ուսումնասիրության համար։

## 21.4. Մոդելի թափանցիկություն

Հետազոտության մոդելը կառուցված է պարզ վիճակագրական ենթադրությունների վրա։

Այս հատկությունը հեշտացնում է ստացված արդյունքների բացատրությունը և սահմանափակումների քննարկումը։

## 21.5. AI-ի կիրառումը վերլուծության մեջ

AI Agent-ը կարող է նվազեցնել հետազոտության արդյունքների ուսումնասիրության տեխնիկական բարդությունը։

Օգտատերը կարող է հարցը տալ բնական լեզվով, իսկ համակարգը՝ ընտրել հաշվարկային գործիքը և ներկայացնել արդյունքները։

Այսպիսով, AI-ը հանդես է գալիս որպես վերլուծական ինտերֆեյս, ոչ թե վիճակագրական հաշվարկներին փոխարինող բաղադրիչ։

# 22. Հետազոտության սահմանափակումները

Նախագիծն ունի մի շարք կարևոր սահմանափակումներ։

**Պատմական տվյալներ**

Տվյալները վերաբերում են 2005 թվականին և կարող են չարտացոլել ներկայիս վարկային շուկայի պայմանները։

**Աշխարհագրական սահմանափակում**

Տվյալները հավաքագրվել են Թայվանում, ուստի արդյունքները չի կարելի անմիջապես ընդհանրացնել Հայաստանի կամ այլ երկրների բանկային համակարգերի համար։

**Խմբային մոդելավորում**

Նախագծի հիմնական մոդելը գնահատում է խմբային default probability։

Այն չի գնահատում յուրաքանչյուր հաճախորդի անհատական PD։

**Պայմանական անկախության ենթադրություն**

Մոդելը խմբի ներսում ենթադրում է ընդհանուր հավանականություն և պայմանական անկախություն։

Իրական աշխարհում կարող են գործել լրացուցիչ կախվածություններ։

**Model calibration**

Held-out validation-ը ցույց է տվել, որ No reported delay խմբում դիտարկված դեֆոլտների քանակը դուրս է կանխատեսված միջակայքից։

**Տնտեսական գործոններ**

Մոդելում ուղղակիորեն ներառված չեն մակրոտնտեսական փոփոխությունները, տոկոսադրույքները, գործազրկությունը և այլ արտաքին գործոններ։

**AI-ի սահմանափակումներ**

Լեզվային մոդելը կարող է սխալ մեկնաբանել որոշ հարցեր կամ տրամադրել ոչ լիարժեք բացատրություններ։

Հետևաբար թվային կարևոր արդյունքները պետք է ստուգել Python հաշվարկային գործիքների միջոցով։

# 23. Հետագա զարգացման հնարավորություններ

6. Մակրոտնտեսական գործոնների ներառում։

Սա կարող է օգտակար լինել հատկապես այն դեպքերում, երբ առանձին ռիսկային խմբերում դիտարկումների քանակը փոքր է։

# 24. Եզրակացություն

Bayesian Credit Risk Intelligence նախագիծը ցույց է տալիս, թե ինչպես կարելի է բայեսյան վիճակագրությունը կիրառել վարկային ռիսկի գնահատման և կանխատեսման խնդիրներում։

Հետազոտության ընթացքում կառուցվել է Beta-Binomial Bayesian Model, գնահատվել են տարբեր ռիսկային խմբերի posterior default probability-ները, իրականացվել են MCMC և posterior predictive վերլուծություններ, ինչպես նաև ուսումնասիրվել է prior assumptions-ի ազդեցությունը։

Առանձնահատուկ ուշադրություն է դարձվել model assessment-ին, որի միջոցով բացահայտվել են ինչպես մոդելի առավելությունները, այնպես էլ նրա կանխատեսողական սահմանափակումները։

R Shiny Dashboard-ի մշակումը հնարավորություն է տվել հետազոտության արդյունքները ներկայացնել ինտերակտիվ միջավայրում։

Google Gemini AI Agent-ի և Python Function Calling-ի ինտեգրումը նախագծին ավելացրել է բնական լեզվով վերլուծության հնարավորություն։

Ընդհանուր առմամբ, նախագիծը ներկայացնում է վիճակագրական մոդելավորման, տվյալների վերլուծության, ծրագրային մշակման և արհեստական բանականության գործնական համադրություն։
